### Notions d'algorithmique

Introduction à la notion d'**algorithme**.

Un algorithme peut être défini comme une **suite d'instructions ordonnées permettant de résoudre un problème donné**. On peut le comparer à une recette de cuisine : chaque étape doit être réalisée dans un ordre précis afin d'obtenir le résultat attendu.

#### Algorithmique débranchée

Découverte de l'**algorithmique débranchée**, qui consiste à apprendre et à comprendre les principes de l'algorithmique sans utiliser directement un ordinateur.

Cette approche permet de se mettre dans la logique d'une machine ou d'un robot en exécutant des instructions étape par étape.

#### Les trois critères d'un algorithme

Pour qu'une suite d'instructions puisse être considérée comme un algorithme, elle doit respecter trois principaux critères :

1. **Une suite ordonnée d'instructions** : les instructions doivent être exécutées dans un ordre logique.
2. **Un nombre fini d'étapes** : l'algorithme doit pouvoir arriver à une fin.
3. **Des instructions précises** : chaque instruction doit être suffisamment claire pour permettre de résoudre le problème donné.
